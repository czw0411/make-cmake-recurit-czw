# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理
2. 编译
3. 汇编
4. 链接

建议控制在 300～500 字，不需要展开复杂细节。

一个 C 程序从 .c 源文件到最终可执行文件，大致经过四个阶段：

## 1. 预处理

编译器先处理以 # 开头的指令：把 #include 的头文件内容原样展开插入到源文件里、把 #define 的宏做文本替换、处理 #if 等条件编译。预处理后生成的文件里已经没有宏和 #include，只剩纯粹的 C 代码。

## 2. 编译

把预处理后的 C 源码翻译成汇编代码（.s 文件）。这一阶段做语法检查、类型检查，并把高级语言逻辑转换成对应的底层指令描述，比如把 a = b + c 变成一条加法指令的形式。

## 3. 汇编

把汇编代码翻译成机器码，生成目标文件（.o 文件）。此时每条指令都变成了 CPU 能识别的二进制形式，但目标文件里还留着"待填空"的引用——比如调用外部函数时只记录"这里要调用某个名字"，具体地址还没定。

## 4. 链接

把多个目标文件（以及用到的库）合并成最终的可执行文件。这一阶段把各个目标文件里互相引用的函数、变量"对上号"，填入真实的内存地址，补全之前留下的空缺，最终产出一个可以运行的程序。
